# Clean ERP 디자인 시스템 (기준 문서)

> 이 문서는 Clean ERP의 **모든 화면 디자인의 단일 기준**입니다.
> 새 화면을 만들거나 기존 화면을 고칠 때 이 문서를 먼저 확인하고, 여기에 없는 스타일은 만들지 않습니다.
> 기준을 바꿔야 한다면 코드보다 **이 문서를 먼저 수정**합니다.

- 상태: v1.2 확정 (2026-09-22). 결정 내역은 [12. 결정 기록](#12-결정-기록) 참고
- 적용 범위: `my-clean-erp/app`, `my-clean-erp/components` 의 모든 UI
- 예외: 인쇄·PDF 출력물(견적서, 거래명세서)은 [10. 출력 문서](#10-출력-문서-견적서거래명세서) 규칙을 따름

## 0. 현재 상태 진단 (2026-09 기준)

| 항목 | 현재 | 문제 |
|---|---|---|
| 인라인 스타일 | `style={{...}}` 약 830곳 | 같은 요소가 페이지마다 다르게 생김 |
| 글자 크기 | 25종 이상 (0.58rem ~ 1.45rem) | 위계가 없음, 0.72 / 0.75 / 0.78 / 0.8 / 0.82 혼재 |

## 1. 디자인 원칙

1. **덜어내기 (Minimal)**
   장식은 쓰지 않습니다. 그림자, 그라데이션, 배경색 박스, 이모지는 없습니다. 정보가 곧 디자인입니다.
2. **지면처럼 (Editorial)**
   화면을 신문이나 잡지의 지면처럼 다룹니다. 박스로 감싸지 않고 **여백과 가는 선(hairline)** 으로 구역을 나눕니다. 위계는 크기보다 **굵기, 색 농도, 여백**으로 만듭니다.
3. **하나의 색**
   흑백(잉크) 계열에 강조색은 **하나만** 씁니다. 상태 색(경고, 오류, 완료)은 글자나 점에만 쓰고 넓은 면을 칠하지 않습니다.
4. **숫자는 정렬되어야 한다**
   ERP의 핵심은 숫자입니다. 금액과 수량은 고정폭 숫자(`tabular-nums`)로 오른쪽 정렬합니다.
5. **어떤 페이지든 같은 뼈대**
   모든 페이지는 같은 순서의 같은 구역(페이지 헤더, 필터 바, 본문)으로 구성합니다.

## 2. 색상

### 2.1 토큰

색은 **반드시 아래 토큰으로만** 사용합니다. TSX나 CSS에 hex 값을 직접 쓰지 않습니다.

| 토큰 | 값 (라이트) | 용도 |
|---|---|---|
| `--c-bg` | `#FAFAF8` | 페이지 바탕 (살짝 따뜻한 종이색) |
| `--c-surface` | `#FFFFFF` | 표, 입력창, 모달 바탕 |
| `--c-subtle` | `#F2F1EE` | hover, 선택된 행, 비활성 입력 |
| `--c-ink` | `#1A1A1A` | 본문 글자, 제목, 주 버튼 |
| `--c-ink-2` | `#5C5C5C` | 보조 글자 (라벨, 설명) |
| `--c-ink-3` | `#8E8E8E` | 흐린 글자 (placeholder, 비활성, 단위) |
| `--c-line` | `#E4E2DD` | 기본 구분선 (hairline) |
| `--c-line-strong` | `#1A1A1A` | 강조 구분선 (표 머리 아래, 합계 위) |
| `--c-accent` | `#1F4E8C` | 주 버튼, 링크, 포커스, 선택 표시 (유일한 강조색) |
| `--c-accent-strong` | `#173C6D` | 주 버튼 hover |
| `--c-accent-soft` | `rgba(31,78,140,0.08)` | 선택된 탭이나 행의 옅은 바탕 |
| `--c-danger` | `#B3261E` | 오류, 미수금, 삭제 |
| `--c-warning` | `#9A6700` | 주의, 기한 임박 |
| `--c-success` | `#1E6B3A` | 완료, 수금됨 |

### 2.2 규칙

- 버튼 색은 **세 가지만** 씁니다 (7.1).
  - 일반 동작: **강조색(`--c-accent`) 바탕에 흰 글자**
  - 취소, 삭제: **`--c-danger`**
  - 보조 동작: 흰 바탕(`--c-surface`)에 `--c-line` 테두리
- 강조색은 버튼 밖에서는 링크, 포커스, 선택 상태에만 씁니다.
- 상태 색은 **글자색 또는 6px 점**으로만 씁니다. 빨간 배경 박스나 노란 배경 배너는 쓰지 않습니다. 경고 배너가 꼭 필요하면 `--c-subtle` 바탕에 왼쪽 2px 상태색 선을 둡니다.
- 그림자(`box-shadow`)는 쓰지 않습니다. 예외는 떠 있는 레이어(드롭다운, 모달)뿐이며 `--shadow-float` 하나만 씁니다.
- 다크 모드는 v1 범위가 아닙니다 (확정). 다만 나중에 토큰 값만 추가해 대응할 수 있도록 색은 반드시 토큰으로만 씁니다.

## 3. 타이포그래피

### 3.1 글꼴

글꼴은 **제목 글꼴**과 **본문 글꼴** 두 역할로 나뉘며, 각각 설정에서 바꿀 수 있습니다.

| 역할 | 토큰 | 기본값 | 적용 위치 |
|---|---|---|---|
| 제목 글꼴 | `--font-heading` | **Noto Serif KR** (명조) | 페이지 제목(h1), 섹션 제목(h2), 모달 제목, 홈 대시보드 핵심 숫자 |
| 본문 글꼴 | `--font-body` | **Pretendard** | 그 밖의 모든 UI (표, 버튼, 입력, 메뉴, 사이드바 앱 이름 포함) |

- 숫자는 본문 글꼴에 `font-variant-numeric: tabular-nums` 를 적용해 열을 정렬합니다.
- 제목 글꼴은 위 네 곳에만 씁니다. 표, 버튼, 탭, 메뉴에는 쓰지 않습니다.
- 컴포넌트는 글꼴 이름을 직접 쓰지 않고 항상 `var(--font-heading)` / `var(--font-body)` 를 씁니다.

#### 선택 가능한 글꼴 (모두 무료 웹폰트, 사용자가 파일을 올리지 않음)

| 제목 글꼴 | 성격 | 본문 글꼴 | 성격 |
|---|---|---|---|
| **Noto Serif KR** (기본) | 단정한 명조, 굵기 다양 | **Pretendard** (기본) | 현대적, 숫자 가독성 좋음 |
| 마루 부리 (MaruBuri) | 부드럽고 현대적인 명조 | Noto Sans KR | 중립적, 가장 무난 |
| 나눔명조 | 익숙한 전통 명조 | IBM Plex Sans KR | 단단하고 기술적인 느낌 |
| 고운바탕 | 따뜻한 손글씨 느낌 명조 | 나눔고딕 | 익숙하고 부드러움 |

- 출처: Pretendard는 jsDelivr, 마루 부리는 네이버 한글 CDN, 나머지는 Google Fonts.
- 로딩: **선택된 두 글꼴만** 불러옵니다. 기본 조합(Noto Serif KR + Pretendard)은 미리 불러오고(preload), 다른 글꼴은 선택했을 때만 `<link>` 로 추가합니다.
- 글꼴마다 대체 스택을 둡니다.
  - 제목: `<선택 글꼴>, "Noto Serif KR", "AppleMyungjo", "Batang", serif`
  - 본문: `<선택 글꼴>, "Pretendard", -apple-system, "Apple SD Gothic Neo", "Malgun Gothic", sans-serif`
- 이모지 폰트(`Apple Color Emoji` 등)는 스택에서 제거합니다.
- 목록에 글꼴을 추가하거나 빼려면 이 표를 먼저 수정합니다.

### 3.2 크기 단계 (5단계만 사용)

모든 크기는 `rem` 입니다. 루트 글자 크기(`html { font-size }`)를 사용자 설정으로 바꾸면 전체가 함께 커지고 작아집니다.

| 토큰 | rem | 기본(14px) 기준 | 용도 |
|---|---|---|---|
| `--fs-xs` | 0.8125rem | 약 11.4px | 표 머리, 배지, 캡션, 단위 |
| `--fs-sm` | 0.9rem | 약 12.6px | 표 본문, 라벨, 보조 설명, 버튼 |
| `--fs-md` | 1rem | 14px | 본문, 입력값 |
| `--fs-lg` | 1.15rem | 약 16px | 섹션 제목 (h2) |
| `--fs-xl` | 1.5rem | 21px | 페이지 제목 (h1) |

- 이 5개 외의 크기는 쓰지 않습니다. (`0.72rem`, `0.78rem`, `0.82rem` 등 금지)
- 대시보드 핵심 숫자(KPI)만 예외로 `--fs-xl` 을 숫자에 사용할 수 있습니다.

### 3.3 굵기 (3단계만 사용)

| 토큰 | 값 | 용도 |
|---|---|---|
| `--fw-regular` | 400 | 본문, 표 값 |
| `--fw-medium` | 500 | 라벨, 버튼, 표 머리, 선택된 메뉴 |
| `--fw-bold` | 600 | 제목, 합계 금액 |

- `700`, `800`, `bold` 는 쓰지 않습니다.

### 3.4 기타

- 줄 간격: 본문 1.55, 표와 UI 1.4, 제목 1.25
- 표 머리(`th`)는 `--fs-xs`, `--fw-medium`, `--c-ink-2`, 자간 `0.02em`
- 금액 표기: `1,234,000원` (천 단위 쉼표, 단위는 `--c-ink-3`)
- 날짜 표기: `2026.09.22` / 월 단위는 `2026.09` (`2026-9`, `9월 22일` 등 혼용 금지)

### 3.5 화면 설정 (글꼴, 글자 크기)

설정 > 일반 탭에 **화면** 묶음을 추가합니다.

```
화면
  제목 글꼴   [ Noto Serif KR   v ]
  본문 글꼴   [ Pretendard      v ]
  글자 크기   [ 보통 (14px)     v ]

  미리보기
    월 정산 등록                 <- 제목 글꼴
    거래처 12곳 · 1,234,000원    <- 본문 글꼴
                                        [기본값으로]
```

| 글자 크기 옵션 | 루트 크기 |
|---|---|
| 작게 | 13px |
| 보통 (기본) | 14px |
| 크게 | 15px |
| 아주 크게 | 16px |

- 저장: **브라우저별** 로 저장합니다 (기존 `utils/appSettings.ts` 의 `general` 에 추가, localStorage). 다른 PC에서는 기본값으로 시작합니다.
- 적용: `<html data-font-size="md" data-font-heading="noto-serif" data-font-body="pretendard">` 속성으로 처리하고, CSS에서 속성별로 `font-size`, `--font-heading`, `--font-body` 를 바꿉니다.
- 설정을 바꾸면 저장 버튼 없이도 미리보기에 즉시 반영하고, 저장 시 전체 화면에 적용합니다.
- 첫 화면이 깜빡이지 않도록 `layout.tsx` 에서 hydration 전에 속성을 적용하는 작은 인라인 스크립트를 둡니다.
- 모바일 입력창은 iOS 확대 방지를 위해 설정과 관계없이 최소 16px를 유지합니다 (기존 규칙 유지).
- **이 기능이 동작하려면 모든 크기가 rem 이어야 합니다.** 글자, 여백, 행 높이에 `px` 를 쓰지 않습니다 (선 두께 1px는 예외).

## 4. 간격과 모양

### 4.1 간격 (4px 단위)

| 토큰 | 값 | 용도 예 |
|---|---|---|
| `--sp-1` | 0.25rem | 아이콘과 글자 사이 |
| `--sp-2` | 0.5rem | 버튼 사이, 라벨과 입력창 사이 |
| `--sp-3` | 0.75rem | 셀 좌우 안쪽 여백 |
| `--sp-4` | 1rem | 구역 안쪽 여백 |
| `--sp-6` | 1.5rem | 구역 사이 |
| `--sp-8` | 2rem | 페이지 헤더 아래 |

### 4.2 모서리

| 토큰 | 값 | 용도 |
|---|---|---|
| `--radius-0` | 0 | 구역, 표, 카드 (에디토리얼: 각진 지면) |
| `--radius-1` | 3px | 버튼, 입력창, 배지, 드롭다운, 모달 |

- 이 두 값 외의 모서리(6, 8, 12px, 원형 버튼 등)는 쓰지 않습니다.

### 4.3 선

- 구역은 **박스로 감싸지 않습니다.** 필요할 때 아래쪽에 가는 선(`1px solid var(--c-line)`) 하나만 둡니다.
- 강조선(`--c-line-strong`)은 표 머리 아래와 합계 행 위에만 씁니다.
- 세로 구분선은 쓰지 않습니다. 열 구분은 여백으로 합니다.

## 5. 아이콘

- **이모지 금지.** Windows와 MS 기본 이모지를 포함한 모든 유니코드 이모지(🏠 📦 ⚠ ✕ ☰ ⚙ 등)는 UI에 쓰지 않습니다. 코드 주석의 ✅ 표시도 새로 쓰지 않습니다.
- 아이콘은 **`lucide-react`** 한 종류만 씁니다. 선 굵기 1.5, 크기 `1em` (글자 크기를 따라감), 색은 `currentColor`.
- 아이콘은 **의미를 보조할 때만** 씁니다. 글자만으로 충분하면 아이콘을 넣지 않습니다.
  - 사이드바 메뉴: 아이콘 사용 (접힌 상태에서 필요)
  - 버튼: 닫기(X), 검색, 새로고침, 인쇄, 다운로드처럼 관용적인 동작에만 사용
  - 제목, 탭, 표 머리: 아이콘 없음. 예외: 사이드바 메뉴처럼 분류를 나누는 탭(재고의 기기 · 소모품 · 부품 · 기타)은 글자 앞에 아이콘을 둘 수 있음
- 닫기 버튼은 `✕` 문자가 아닌 `X` 아이콘을 씁니다.
- 경고 표시는 `⚠` 대신 `--c-warning` 색 글자로 처리합니다. 아이콘이 필요하면 `AlertTriangle` 을 씁니다.

## 6. 페이지 뼈대 (모든 페이지 공통)

```
┌ 페이지 헤더 ───────────────────────────────────────────┐
│ 페이지 제목 (h1, serif)                  [보조] [주 버튼] │
│ 한 줄 설명 (--fs-sm, --c-ink-2, 선택)                    │
├ 필터 바 (테두리 없음, 아래 hairline) ───────────────────┤
│ 검색  기간  구분  [조회]            요약: 총 12건 · 합계 │
├ 본문 ───────────────────────────────────────────────────┤
│ 표 / 목록 / 폼                                          │
└─────────────────────────────────────────────────────────┘
```

규칙:

1. **페이지 헤더**: 제목은 왼쪽, 동작 버튼은 오른쪽 끝에 둡니다. 주 버튼은 페이지당 1개입니다. 제목 아래 여백은 `--sp-6` 입니다.
2. **필터 바**: 테두리나 배경 박스 없이 한 줄에 배치합니다. 입력은 왼쪽부터, 요약 수치(총 건수, 합계)는 오른쪽 끝에 둡니다. 좁은 화면에서는 줄바꿈합니다. 필터 바 아래에만 hairline을 둡니다.
3. **본문**: 표는 페이지 폭을 가득 채웁니다. 카드나 박스로 한 번 더 감싸지 않습니다.
4. **섹션이 여럿인 페이지**(설정, 홈 등): 섹션 제목(h2, `--fs-lg`, `--fw-bold`)과 그 아래 hairline으로 나눕니다. 섹션 사이 여백은 `--sp-8` 입니다.
5. **탭**: 밑줄형만 사용합니다 (선택 탭은 `--c-ink` 2px 밑줄과 `--fw-medium`). 알약형이나 박스형 탭은 쓰지 않습니다.

### 정렬 규칙

| 내용 | 정렬 |
|---|---|
| 글자 (거래처명, 메모 등) | 왼쪽 |
| 숫자 (금액, 수량, 카운터) | 오른쪽 + `tabular-nums` |
| 날짜, 상태 배지, 체크박스 | 가운데 |
| 행 동작 버튼 | 오른쪽 끝 열 |
| 표 머리 | 해당 열의 정렬을 따름 |

- 폼의 라벨은 **입력창 위**에 둡니다 (왼쪽 라벨 방식 금지). 예외는 설정 화면의 짧은 토글 행입니다.
- 한 줄 안의 요소는 세로 가운데 정렬(`align-items: center`)을, 라벨이 있는 입력 묶음은 아래 정렬(`flex-end`)을 기본으로 합니다.

## 7. 컴포넌트 규칙

모든 공통 요소는 `components/ui/` 의 컴포넌트를 씁니다. 페이지에서 버튼이나 입력창을 직접 스타일링하지 않습니다.

### 7.1 버튼 (`Button`)

버튼 색은 아래 **세 가지만** 씁니다. 페이지에서 버튼 색이나 크기를 따로 정하지 않습니다.

| variant | 모양 | 용도 |
|---|---|---|
| `primary` | `--c-accent` 바탕, 흰 글자, hover `--c-accent-strong` | 일반 동작: 저장, 등록, 조회, 확인 |
| `danger` | 흰 바탕, `--c-danger` 테두리와 글자 | **모든 취소 버튼**과 삭제 (삭제는 항상 확인 절차) |
| `secondary` | 흰 바탕, `--c-line` 테두리, `--c-ink` 글자 | 보조 동작: 닫기, 엑셀, 인쇄, 새로고침, 행 안의 수정 |

- `ghost` 는 **아이콘만 있는 버튼**(닫기 X, 사이드바 접기)에만 씁니다. 글자가 있는 ghost 는 `secondary` 와 같게 보입니다. `outline` 은 `secondary` 의 이전 이름입니다.
- 크기는 **한 가지**입니다: 높이 2.125rem, 좌우 안쪽 여백 `--sp-3`, 글자 `--fs-sm`, `--fw-medium` (월 정산 등록의 [조회] 버튼 기준). 폭은 글자 길이를 따르며 `min-width`, `width: 100%`, 모바일용 크기 변경을 두지 않습니다. 예외는 로그인·가입 화면의 제출 버튼(폼 폭 가득)입니다.
- `size="sm"` (1.75rem 정사각형)은 아이콘만 있는 버튼에만 씁니다.
- hover 효과는 배경색 변화만 둡니다 (확대, 그림자, 이동 없음).
- 탭, 기간 선택 같은 토글, 표 머리 정렬, 달력 칸, 링크처럼 보이는 글자 버튼은 이 규칙의 버튼이 아닙니다.

### 7.2 입력창 (`Input`, `Select`, `ComboBoxSelect`)

- 높이는 `md` 버튼과 같은 2.125rem입니다. 테두리 `--c-line`, 바탕 `--c-surface`, 모서리 `--radius-1`.
- 포커스: 테두리 `--c-accent` + 바깥 1px `--c-accent-soft` 링.
- 라벨: 위쪽, `--fs-xs`, `--fw-medium`, `--c-ink-2`, 아래 여백 `--sp-1`.
- 오류: 테두리 `--c-danger`, 입력창 아래에 `--fs-xs` 빨간 글자 한 줄.

### 7.3 표

- 바깥 테두리와 세로선이 없습니다.
- 머리: 아래 1px `--c-line-strong`, 글자 `--fs-xs` / `--fw-medium` / `--c-ink-2`.
- 행: 높이 2.5rem, 아래 1px `--c-line`, hover 시 `--c-subtle`.
- 합계 행: 위 1px `--c-line-strong`, `--fw-bold`.
- 줄무늬(zebra) 배경은 쓰지 않습니다.
- 밀도는 **보통 한 가지로 고정**합니다 (행 높이 2.5rem). 조밀 모드나 밀도 설정은 두지 않습니다.
- 가로 스크롤은 기존 `.tableScroll` 을 씁니다.

### 7.4 상태 배지

- 형태: `● 텍스트` (6px 점 + `--fs-xs` 글자). 배경을 칠하지 않습니다.
- 점 색상: 완료 / 수금 `--c-success`, 대기 / 주의 `--c-warning`, 미수 / 오류 `--c-danger`, 기타 `--c-ink-3`.

### 7.5 모달

- 바탕 `--c-surface`, 모서리 `--radius-1`, `--shadow-float`, 뒤 배경 `rgba(26,26,26,0.32)`.
- 구성: 제목(`--fs-lg`) → 본문 → 하단 버튼 (오른쪽 정렬, 취소 → 주 버튼 순).
- 닫기 아이콘은 오른쪽 위에 `X` 아이콘 ghost 버튼으로 둡니다.

### 7.6 알림, 빈 상태, 로딩

- 빈 상태: 가운데 정렬 `--fs-sm` `--c-ink-3` 한 줄 (예: "조건에 맞는 청구 이력이 없습니다."). 그림이나 이모지는 쓰지 않습니다.
- 로딩: "불러오는 중…" 글자 또는 표 자리의 옅은 막대(skeleton). 회전하는 아이콘은 최소화합니다.
- 안내 문구: `--fs-sm` `--c-ink-2` 한 단락. 박스나 배경 없이 씁니다.
### 7.7 확인창과 알림 (브라우저 기본 창 교체)

브라우저 기본 `alert()` / `confirm()` / `prompt()` 는 **쓰지 않습니다.** 페이지별 적용 단계에서 모두 교체합니다.

| 기존 | 교체 | 모양 |
|---|---|---|
| `confirm()` | `useConfirm()` → `ConfirmDialog` | 7.5 모달 규칙을 따름. 제목, 설명 한두 줄, [취소] [확인]. 취소 버튼은 항상 `danger`, 확인 버튼은 `primary` (삭제 확인이면 `danger`) |
| `alert()` (결과 알림) | `toast()` → `Toast` | 화면 아래 가운데, `--c-ink` 바탕에 흰 글자 한 줄, 3초 후 사라짐. 오류는 왼쪽에 `--c-danger` 2px 선 |
| `alert()` (꼭 읽어야 하는 오류) | `ConfirmDialog` (확인 버튼만) | 저장 실패처럼 사용자가 행동해야 하는 경우 |
| `prompt()` | 입력창이 있는 모달 | 7.2 입력창 규칙을 따름 |

- `useConfirm()` 은 `await confirm({ title, description, danger })` 처럼 Promise로 결과를 돌려주어, 기존 `if (!confirm(...)) return` 코드를 한 줄씩 바꿀 수 있게 만듭니다.
- 토스트는 한 번에 최대 3개까지 쌓입니다.

## 8. 레이아웃 셸 (사이드바, 헤더)

- 사이드바: 바탕 `--c-bg`, 오른쪽 hairline. 메뉴 글자 `--fs-sm`. 선택 메뉴는 `--c-ink` 글자와 `--fw-medium`, 왼쪽 2px 잉크 막대를 둡니다 (배경 칠 없음).
- 상단 헤더: 높이 유지, 아래 hairline, 그림자 없음.
- 본문 최대 폭: 제한 없음 (표 중심 ERP). 다만 폼 위주 페이지(설정, 등록 폼)는 본문 폭을 `48rem` 으로 제한합니다.

## 9. 코딩 규칙 (개발 시 반드시 지킬 것)

1. **토큰만 사용**: 색, 글자 크기, 굵기, 간격, 모서리는 `var(--*)` 토큰으로만 씁니다. hex 값과 임의 `rem` / `px` 값은 금지입니다.
2. **인라인 스타일 최소화**: `style={{}}` 는 동적인 값(폭 계산, 위치 등)에만 씁니다. 색, 글자, 여백, 테두리는 CSS Module 클래스로 처리합니다.
3. **공통 컴포넌트 우선**: 버튼, 입력, 표, 배지, 모달, 탭, 페이지 헤더, 필터 바는 `components/ui/` 컴포넌트를 씁니다. 없으면 먼저 `ui/` 에 만들고 씁니다.
4. **이모지 금지**: UI 문자열과 JSX에 이모지를 넣지 않습니다. 아이콘은 `lucide-react` 만 씁니다.
5. **새 스타일 금지**: 이 문서에 없는 색이나 크기가 필요하면 코드에 넣지 말고 이 문서에 먼저 추가를 제안합니다.
6. **토큰 이름 이전**: 기존 `--notion-*` 토큰은 이전 기간 동안 새 토큰의 별칭으로 남겨 두고, 새 코드에서는 쓰지 않습니다.

### 검사 명령 (작업 후 확인)

```bash
# 이모지 (0건이어야 함)
LC_ALL=C.UTF-8 grep -rnP "[\x{1F300}-\x{1FAFF}\x{2600}-\x{27BF}\x{2B50}]" app components --include=*.tsx
# TSX 하드코딩 색 (0건이어야 함)
grep -rnE "#[0-9a-fA-F]{3,6}\b" app components --include=*.tsx
# 폐지된 굵기
grep -rnE "font-?[wW]eight:? ?['\"]?(700|800|bold)" app components
```

한 번에 모두 바꾸지 않고 아래 순서로 진행합니다. 각 단계는 별도로 승인받고 진행합니다.
